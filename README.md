# 🏋️ Strivox

Strivox es una landing page desarrollada como proyecto práctico del curso **Full Stack Developer**. El objetivo es diseñar la interfaz de un gimnasio moderno, aplicando buenas prácticas de HTML y CSS.

> ⚠️ Este proyecto se encuentra en desarrollo. Actualmente solo cuenta con la parte Frontend.

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome

## ✨ Características

- Diseño responsive.
- Navbar con indicador de página activa.
- Hero principal con llamada a la acción.
- Sección de planes con tarjetas comparativas.
- Footer con enlaces y redes sociales.
- Uso de variables CSS para facilitar el mantenimiento de estilos.

## 🎯 Objetivo del proyecto

Este proyecto nació con la idea de convertirse en una aplicación Full Stack.

### MVP (Frontend)

- Landing Page
- Planes del gimnasio
- Navegación entre páginas
- Diseño responsive

### Próximas funcionalidades (Backend)

- Registro e inicio de sesión.
- Gestión de usuarios.
- Compra de membresías.
- Reserva de clases.
- Perfil del usuario.
- Seguimiento de entrenamientos.
- Base de datos con planes y usuarios.
